01 / Sprache

Fünf Sprachen zur Auswahl.

Deutsch, Englisch, Französisch, Spanisch und Niederländisch sind direkt eingebaut. In den Browser-Einstellungen kannst du die Sprache wechseln; Deutsch bleibt die Voreinstellung.

02 / Fundament

Firefox als Basis.

Rosavio wird aus dem Firefox-Quellcode gebaut. Mit eigenem Namen, eigenem Erscheinungsbild und einem eigenen Browserprofil.

03 / Weiterentwicklung

Updates, die mitgehen.

GitHub prüft regelmäßig neue Firefox-Versionen. Neue Rosavio-Versionen werden gebaut, signiert und getestet, bevor sie über das Autoupdate bereitstehen.

Noch eine Frage?

Muss ich die alte Version vorher deinstallieren?

Nein. Schließe Rosavio vollständig und installiere die neue Version im selben Ordner. Dein bisheriges Browserprofil mit Lesezeichen und Einstellungen bleibt dabei erhalten.

Was passiert, wenn mein PC ausgeschaltet ist?

GitHub kann neue Versionen auch dann vorbereiten. Herunterladen und installieren kann dein Rosavio ein Update erst, wenn dein PC wieder eingeschaltet ist und der Browser nach Updates suchen kann.

Für welche Geräte gibt es Rosavio?

Aktuell gibt es eine deutsche Version für Windows mit 64-Bit-Prozessor. Die Setup-EXE findest du über die Download-Knöpfe auf dieser Seite.

Ist Rosavio ein Angebot von Mozilla?

Rosavio ist ein eigenständiges Projekt auf Firefox-Basis und kein offizielles Mozilla-Produkt. Den Quellcode, die Anpassungen und Lizenzinformationen findest du im GitHub-Projekt.

Wo kann ich einen Fehler melden?

Über die GitHub-Projektseite für Fehlermeldungen. Beschreibe möglichst genau, was passiert ist und welche Rosavio-Version du verwendest. Veröffentliche dabei keine Passwörter oder anderen privaten Daten.
