Et frisk blik på nettet.

Rosavio er en selvstændig browser baseret på Firefox med sin egen profil og egne opdateringer.

Signerede opdateringer

GitHub søger efter nye stabile Firefox-versioner dagligt omkring kl. 18 tysk tid. Pakkerne signeres og testes.

Installation

Luk Rosavio, og installer den nye version i samme mappe. Bogmærker og indstillinger bevares i profilen.

De ekstra browsersprog bliver bygget og testet.
